# Site Concurso Agrinho: "Agro forte, futuro Sustentável" 🌾

## 📝 Descrição do Projeto
Este projeto consiste em um site educacional e inspirador desenvolvido para o **Concurso Agrinho**. O objetivo é apresentar a força do agronegócio brasileiro aliada à preservação ambiental, utilizando dados reais de instituições como Embrapa, Ministério da Agricultura e Pecuária (MAPA) e IBGE.

## 🎯 Objetivo
Informar estudantes e a comunidade sobre como a tecnologia e as práticas sustentáveis (como ILPF, Plantio Direto e Bioinsumos) permitem que o Brasil aumente sua produtividade sem comprometer seus ecossistemas naturais, focando na premissa de "produzir conservando".

## 🚀 Tecnologias Utilizadas
- **HTML5**: Estrutura semântica para melhor acessibilidade e SEO.
- **CSS3**: Layout moderno, responsivo (Mobile First) e paleta de cores inspirada na natureza.
- **JavaScript**: Lógica para interações de menu mobile, navegação suave (smooth scroll) e animações de surgimento de conteúdo durante a rolagem (Scroll Reveal).

## 💻 Como Visualizar o Projeto
1. Baixe os três arquivos principais (`index.html`, `style.css`, `script.js`).
2. Mantenha os três arquivos na mesma pasta.
3. Abra o arquivo `index.html` em qualquer navegador moderno (Chrome, Firefox, Edge, etc.).
